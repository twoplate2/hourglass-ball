先统一三个不同的“进度”

  • 计时进度：elapsed / duration。它表示时间经过多少。
  • 供沙进度：已经从出口释放的沙量 / 本局总沙量。上腔和颈部还没释放的部分仍属于剩余砂。
  • 落地进度：已经进入下沙堆的沙量 / 本局总沙量。供沙与落地之间的差额是在途沙，不能把计时99%当成下腔已装入99%。

总沙量Q应在上腔、颈部、在途、下堆之间守恒。飞溅和表面纹理是视觉效果，不能再额外计入一份沙量。Q最终取下腔容量的100%还是90%，属于待确认的基础形态要求。

基础形态及用户五项表现：标准草案

类型应建立的期望不通过的表现
0. 容器基础比例与周期档位单独定义玻璃颈部的内部净宽、外宽、长度和肩部连接。1秒、5秒作为短周期档，评估比现状更宽的颈部；二者允许同宽。用颈内净宽/球内直径报告比例，固定尺寸比较。目标数值待形态确认。把沙柱画宽冒充颈部加粗；减薄玻璃线凑净宽；单局中颈宽自行变化；只看参数最大值就宣布短周期比例合格。
1. 上部储沙的流动与汇入分别验收沙面下降、浅漏斗、表面起伏、内部细纹流动和入口汇入。整体沉稳，入口附近下行与向中心运动协调；靠近空态/满态不出现失控起伏。沙面突跳、整块贴图抽动、纹理闪烁、空中凹坑或上沙在减而入口冻结。不能用高度下降替代内部流动验收。
2. 落点冲击、飞溅、铺开与堆积把四个动作分别验：先触地，再产生接触反应；飞溅连续回落；铺开局限表层；主体随真实落地量增长。先确认“铺开”接受纹理运动还是要求可辨认颗粒滚动，不混称。未触地先飞溅、悬空、喷雾、表层整片抖动、堆顶突跳或整体流动。飞溅少不能单独证明断供，飞溅多也不能证明落点正确。
3. 沙柱内部的下落与粒子连续逐粒身份、完整二维位置与可见图元对应；纹理随粒子移动，正常尺寸能读出持续下行。出生、接触、遮挡及回收有明确原因。数据与像素分别核对。慢滚贴图、固定色杆、长丝、倒流感、横向/纵向瞬移、空中重随机或成片开关。图元跟随已瞬移的坐标也应失败。
4. 沙柱宽度、轮廓与边缘分别验主流宽度、可见外缘、细粒尺度、独立边粒与整体轴线。颈内与出口比例连续，主体饱满，细碎变化沿下行推进；不强制整束宏观摆动。出口突然增粗、整束同步扭动或呼吸、矩形实心杆、串珠、长直空槽及成排断带。最坏帧和连续异常片段不能被平均值掩盖。
5. 各段接口与全过程衔接上沙→颈部、颈部→自由柱、自由柱→落点、落点→下堆分别确认颜色、粒度、速度方向、可见边界及事件顺序。使用不同表现类型允许存在，转换必须连贯。材质/粗细突然换档、硬帽或蒙版、两段交错冻结；恢复重排；结束时整柱瞬间清空。2px图形重叠不能自动证明自然衔接。

计时结束与完成常驻计时到T后停止running，但继续更新在途沙和飞溅；全部落定后保持下堆。明确区分“时间到”和“全部落定”。完成常驻不继续增长，不循环飘砂；是否允许收尾期直接重开另列交互标准。

已核对的周期差异与新缺项

  • 颈宽现状：同一400×800记录中，1秒/5秒外颈宽36px、颈内净宽约23.37px；50秒分别30px和17.37px。球内直径约339.37px，净宽比例约6.9%与5.1%。这些是现状，不是验收目标。短周期颈部是否仍偏细，应作为基础形态标准确认。
  • 首落地时序：本轮同源码540×924、5秒/50秒只读补录中，首批出生约0.25秒、首次落地约1.53秒；对5秒约占31%计时，对50秒约占3%。这说明需要定义短周期首落地期望，不证明该现状一定错误。
  • 近满工况：同轮记录中，中央堆面首次不再属于自由表面，5秒约在4.96秒，50秒约在47.23秒。约99%计时时两组均仍有在途沙；不能把飞溅衰减写成已经完全停止供沙。这些时间仅对应本次尺寸、种子和默认配置。
  • 有时序的纹理与独立粒子不同：上沙浅漏斗随耗沙比例变化，轮廓起伏按默认48秒周期变化，材质还包含开局0.3秒混合及不同用途的时间变量。5秒/50秒相同进度不保证相同纹理相位；应要求平滑与语义一致，不能要求像素完全同相。
  • 粒子边缘不等于粒子中心：物理横向约束会为旧粒径预留空间，而现绘制图元按1.6×pitch确定半径。实际可见宽度还需加上图元边界，不能以中心没有出界证明沙柱没有外扩。
  • 飞溅与铺开存在两个独立关闭条件：即使仍发生碰撞，非自由表面可拒绝飞溅，铺开纹理也会得到零覆盖。这里缺少的是已确认的末段表现规范，不能靠“仍有粒子”直接宣布视觉完整。

本轮应先确认的标准

  1. 基础形态：1秒/5秒共用短周期档已确认；继续确认最粗、最细净宽比例及颈长，随后再校准中间时长函数。
  2. 上沙类型：大块沉稳、近入口更活跃的纹理流动是否作为目标；不要求在密集储沙体中逐颗追踪。
  3. 接触类型：接受局部纹理铺开，还是另要求可辨认的颗粒滚动；不可把前者当后者已实现。
  4. 短周期时序：1秒、5秒、50秒分别明确注颈和首次落地的可接受表现，不先用未经验证的统一百分比定死。
  5. 近满期望：供沙尚未结束时应能读到持续入沙；飞溅可以随空间减少而收敛。容量100%/90%以及对应初末形态留待这些标准确认后决定。
