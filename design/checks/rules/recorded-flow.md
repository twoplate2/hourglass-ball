# 沙漏外观回归检查清单

以正常尺寸原速播放一次完整的 1 秒、5 秒和 15 秒计时，同时保留逐帧的原图、时间戳和沙量。补看 20 秒、50 秒与 100 分钟的首落。每一项都对照同一次启动的计时，记录失败档位和时间。

| 检查部位 | 操作和通过条件 | 3.36 录屏留下的反例 |
| --- | --- | --- |
| 开场满杯 | 开始前和重置后，上杯金沙填成一颗完整的圆球，靠颈一侧的圆弧与玻璃内球贴合，杯颈及下杯留空。按下后跟踪沙底进入杯颈，核对上杯减量、颈内增量和过口沙量。 | 1、5、15 秒待机时上杯顶部各有约 60、37、28 个原始录屏像素的空隙。 |
| 杯颈与沙柱 | 在稳定流动段比较颈内和出口下方的致密宽度。正常尺寸图中至少保留颈内宽度的 92%。再看两侧颗粒能否从贴壁滑动逐渐变成自由下落，颜色、颗粒和速度都应连续。 | 出口短短几行内致密宽度缩去约六分之一。 |
| 首批沙的前缘 | 从按下按钮算到画面首次触地，按原速观察四分之一、半程及四分之三落程。下方先空，前缘连续推进，只在真实触地后逐渐成堆。1、5、15 秒的首落时间分别检查 0.14–0.26、0.30–0.64、0.80–1.50 秒。20 秒及以上在参考画布上约 1.2–1.65 秒，口径随时长收细。抽帧读数允许一帧量化误差。 | 1、5 秒档约 0.09、0.12 秒就触底，5 秒档的前缘在约 0.07 秒内跨过约 580 个录屏像素。 |
| 柱内速度 | 用同一批连续原图分别追踪柱心的上、中、下三处纹理，并单独看贴壁颗粒。入口匹配颈内，入柱后逐步加速，每一档都能看清有方向的颗粒运动。15 秒档的三个实测速度应递增，末处为首处的 1.10–1.47 倍。 | 15 秒档实录的柱心三处约为 181、180、180 像素/秒。 |
| 每秒出沙与可见总量 | 从满杯一直记录到最后落定，按有效计时时长检验累计出沙比例 `t/T`、逐秒窗口和总量。1 秒档另看每四分之一秒。以原图独立估算出口两侧体积，首落前后和截止时刻均须在满杯 2.5 个百分点内。 | 15 秒档首次触地时，出口两侧合计估算仅约为初始沙量的 93.6%，后来才逐渐补回。 |
| 落点与飞溅 | 按相同的约 24%–60% 进度看 1、5、15 秒档。沙柱接到实际堆面，两侧有可辨的零星飞溅。检查快速涨堆、玻璃边界和近满状态，确保埋入坡面的沙保持被遮挡。 | 1 秒档的粗柱几乎没有可见飞溅，15 秒档却出现大片。 |
| 换色后的接缝 | 从金沙切换到蓝沙或绿沙，马上调整颗粒并播放。检查上下沙面、堆尖和飞溅使用新配色。 | 复查时先换蓝沙再改变颗粒，堆尖和上沙边缘残留金色。 |
| 暂停、重置与到点 | 正常按钮开始计时，用独立秒表记录第一帧显示零的时刻。暂停期间计时和主沙冻结。重置后回到满上杯。到点立即停止供沙，只让在途沙落定。 | 调慢首落或改衔接时，复查短计时与收尾，避免引入超时或悬沙。 |

## 修订后的复查口径

- **沙底与容量。** 从开场上杯沙底到落定下杯沙面，统一按玻璃实际内缘计入杯颈。以开场为 100%，逐帧可见总量容差为 2.5 个百分点，落定相对开场的误差单独限为 0.5 个百分点。分别用三组金沙取色阈值复算端点。同步核对每档按有效计时均匀出沙，1 秒档每四分之一秒核一次。
- **首尾两个圆球。** 用 3.19 的待机和落定画面对照 1、5、15 秒档。沿玻璃轴对齐，把开场上杯翻转叠到落定下杯上。在朝向杯颈的中央及两肩取样，横向覆盖半径的 80%。半径约 209 像素时，轮廓各点与内球圆弧的偏差应在 3 像素以内，杯颈留空。
- **归零前后的轮廓。** 上杯最后一薄层贴壁下降，露出的表面近似水平，边缘有轻微起伏。另看接收沙子的下杯，随落沙逐渐形成圆顶。逐帧跟到最后几粒落定，留意两侧深槽、直立沙块、归零瞬间换图，以及完成时突然向空颈上喷的沙子。用原速复看这段过程。
- **前端与柱内运动。** 同时测首次触地时间及前端附近同一批纹理的位移；两者都通过后再看原速。稳定阶段在同一自由落程的四个等距位置跟踪纹理，使用多个帧间隔复算。比较三段增量，确认下半段仍逐渐加快，出口连续且落点可辨。
- **时序与相邻档位。** 用正常开始按钮和独立墙钟测首次显示零，记录按下、暂停、恢复、归零及重置。20 秒、50 秒和 100 分钟将首落按原速并排，比较按下后同一时刻的前沿和首次触地。另取不同窗口尺寸与蓝色粗沙检查颈口、堆面和配色。量具采样率和实际运行帧率分开记录。
- **落点纹理。** 选蓝沙、颗粒 5 档，近看最后一层与落定后的颈口。表面和下一层的沙粒应同样清晰，不应出现向两侧张开的条纹。用 `verify_receiving_pixels.py --renderer native` 核对表层和下杯沙体的纹理坐标，再切换落点层复核图像。原失败帧中条纹会随落点层一起消失。

## 运行方式

在 Windows 上从项目根目录执行。输出目录选用本机临时位置，每次取图使用一个新目录。以下示例采到 15 秒供沙结束后的余沙落定。

```powershell
python -B src/tools/test_recorded_flow.py
python -B src/tools/capture_stream_motion.py --period 15 --start 0 --seconds 15.5 --fps 60 --output "$env:TEMP/hourglass-check-15"
python -B src/tools/check_recorded_flow.py "$env:TEMP/hourglass-check-15"
python -B src/tools/check_visible_sand_volume.py "$env:TEMP/hourglass-check-15"
```

其余短档沿用上述方法，1 秒档建议取 120 帧/秒，方便跟踪第一批沙粒。在 20 秒、50 秒和 100 分钟档分别取开场 2.7 秒，用 `check_recorded_flow.py <取图目录> --opening-only` 检查。完整体积检查需要从开场到落定的连续取图。图像量具采用金沙，其他配色与颗粒档位另外看原图。自动检查接入本地推送钩子和 GitHub CI 的无窗口单测，原图和原速观看记录留在本地。
