# 沙子流动的检查资料

浏览入口：[打开检查目录](index.html)。

这里分为三个目录，目录和文件名保持英文，正文使用中文：

1. [rules：规则与用例](rules/sand-flow.html)。按上沙、下沙、颈部及连接处分组，
   共 33 个固定编号，每组先看整体表现，再看局部。一个编号对应一项表现，
   都有操作、预期、配图、所需证据和关联检查。
2. [records：按版本留记录](records/index.html)。每个版本列出全部编号，逐项写实际现象、
   是否测试通过、检查人和证据；保存实际截图、原始日志和未测项；
   已有 2.96 安装版完整过程、暂停恢复录像及阶段实图；旧容器片段单独保留，不把素材齐备写成通过。
3. [notes：备注与不能再犯的错](notes/index.html)。版本变化、旧判据、证据规则、历史误判与流程缺口。

详细执行说明见 [改完以后怎么检查](rules/how-to-check.md)。
自动检查入口读取 [rules/checklist.json](rules/checklist.json)；脚本仍在 `src/tools/`。

图文用例由 [rules/sand-flow-cases.json](rules/sand-flow-cases.json) 生成。
新增或修改用例后，执行下面的**资料生成命令**，它不启动应用、不执行测试：

```powershell
python -B src/tools/build_sand_flow_docs.py
```

这会更新规则图文页，以及按同一套用例编号整理的版本记录页。
新版本可用 `python -B src/tools/build_sand_flow_docs.py --new-record 版本号` 建立记录：
所有编号默认未测，同时保留规则快照，并自动加入版本目录页；不会覆盖同版本同日记录。
用例中的“关联自动检查”不是“这些脚本已完整覆盖该用例”；动态、外观和声音仍须真实证据。
规则页每个编号都有本次安装版实图。运动项采用原速短循环，开局与末段用不循环片段；
版本记录保留完整录像。循环回到起点是播放器行为，不是应用重开。
录像无音轨，只作动态观察；像素测量用原始 PNG，不能用压缩视频或其封面代替。
采集仅在指定 MuMu 完成，本机未启动 PC 应用测试或浏览器验收，也没有执行本地回归。
